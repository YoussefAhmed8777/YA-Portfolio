Q: "MongoDB duplicates on reconnect in a Node service."

A: Almost always a missing idempotency key on the write path. I'd start by instrumenting the retry logic — log every insert with a client-generated UUID and check if it's being fired twice. If yes, it's a connection-pool race. Fix with a unique index and an upsert.

Q: "Angular change detection is re-rendering my whole tree."

A: OnPush everywhere is the easy fix, but the honest answer is you've got a shared object reference mutating in place. Switch to immutable updates on the slice that's causing it, then add OnPush. Two separate problems, two separate fixes.
